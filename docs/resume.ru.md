# SmartPodbor — проект для резюме

## Краткий блок для раздела «Проекты»

**SmartPodbor — Telegram-бот для подбора смартфонов**
Учебный проект / портфолио Python-разработчика · октябрь 2026

**GitHub:** [Sasambatra/smartpodbor-bot](https://github.com/Sasambatra/smartpodbor-bot)

**Стек:** Python, asyncio, aiogram 3, SQLite, aiosqlite, pytest,
pytest-asyncio, Ruff, Docker, GitHub Actions.

- Реализован диалог из восьми вопросов с подбором до трёх смартфонов,
  объяснением выбора и ссылками на Яндекс Маркет, Ozon и Wildberries.
- Разработаны строгая фильтрация по бюджету, ОС, памяти и обязательным
  функциям, взвешенное ранжирование и проверка JSON-каталога.
- Добавлены сохранение состояния FSM в SQLite, срок жизни сессий,
  возврат к вопросам и защита от повторных и устаревших нажатий.
- Написаны 82 автоматических теста; общее покрытие операторов и ветвей —
  86,42% по локальной проверке. Подготовлены CLI-демо, Docker-сборка
  и workflow GitHub Actions для Python 3.11 и 3.14.

**Проверено в GitHub Actions:** Python 3.11, Python 3.14 и сборка/демо Docker —
[успешный запуск CI](https://github.com/Sasambatra/smartpodbor-bot/actions/runs/40934558688).

## Описание в одно предложение

Асинхронный Telegram-бот на Python: собирает предпочтения пользователя,
подбирает смартфоны с объяснимым ранжированием и сохраняет прогресс
опроса в SQLite; включает тесты, автономное демо и Docker-конфигурацию.

## Коротко для отклика работодателю

В портфолио есть SmartPodbor — Telegram-бот на Python и aiogram 3
с рекомендательным алгоритмом, SQLite-хранилищем состояния и тестами.
В проекте разделены логика подбора, Telegram-обработчики и работа с данными;
есть воспроизводимое демо, документация и конфигурация CI.

## Что можно показать на техническом собеседовании

1. Как FSM и сохранение состояния позволяют продолжить опрос после перезапуска.
2. Почему обязательные требования проверяются до ранжирования.
3. Как обработка событий и идентификаторы вопросов защищают от двойных нажатий.
4. Как тестировать реальные обработчики aiogram без Telegram-токена.
5. Как проверяются каталог, содержимое пакета и воспроизводимость демо.

## Границы проекта

Основа — официальный MIT-пример FSM-бота aiogram; исходный пример и атрибуция
сохранены. Анкета, каталог, рекомендательный алгоритм, SQLite-хранилище,
обработка кнопок, демонстрация и проверки добавлены в этом проекте.

Каталог содержит 16 моделей и 22 конфигурации. Цены ориентировочные;
ссылки открывают поиск на площадках, наличие и продавцы не проверяются.
Это портфолио-проект с открытым исходным кодом. Актуальный результат CI
доступен во вкладке Actions репозитория; локальные результаты проверок
зафиксированы в документации.
